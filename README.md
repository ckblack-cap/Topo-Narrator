# Topo-Narrator
Long-form narrative generation requires maintaining multi-dimensional consistency over extensive contexts, covering long-term constraints in character settings, event causality, spatial rules, and worldviews. Existing methods compress these heterogeneous elements into homogeneous representations, creating a topological mismatch that lowers retrieval signal-to-noise ratios and induces long-range logical collapse. We propose \textsc{Topo-Narrator}, a framework built on two complementary decouplings. Heterogeneous Topological Memory (HTM) organizes narrative state into a Character Graph, a Plot Chain, and an Environment Tree, providing topology-specific inductive biases. Plan-Reason-Write (PRW) multi-agent collaboration separates high-level reasoning, memory retrieval, and stylistic realization across dedicated agents. Experiments on MoPS and WritingPrompts show that \textsc{Topo-Narrator} consistently generates coherent narratives averaging over 13,000 words and substantially outperforms strong baselines on HANNA quality and Fine-grained consistency metrics, validated by three frontier LLM judges and human evaluation.
